# Snap-Chat 💬

A full-stack real-time chat application built with modern web technologies. Snap-Chat offers one-to-one and group messaging, instant notifications, admin controls, and a secure and responsive user interface.

## 🌐 Live Demo
[🚀 Visit Snap-Chat](https://snap-chat.onrender.com/)

## 📁 GitHub Repository
[📦 Source Code](https://github.com/rjrahulraj/CHAT-APP)

---

## ✨ Features

- 💬 **Real-Time Messaging**  
  Send and receive messages instantly using **WebSockets (Socket.IO)**.

- 👥 **One-to-One & Group Chat**  
  Communicate in personal messages or create group chats with multiple participants.

- 🔔 **Instant Notifications**  
  Get notified in real-time when new messages arrive.

- 🛡️ **Authentication & Authorization**  
  Secure sign-up/login with JWT-based token authentication.

- 🧑‍💻 **Admin Controls**  
  Admins can manage group members and perform moderation actions.

- 📱 **Responsive Design**  
  Built with **React.js** and **Tailwind CSS** for optimal mobile and desktop experience.

---

## 🛠️ Tech Stack

| Layer        | Technologies                             |
|--------------|------------------------------------------|
| Frontend     | React.js, Tailwind CSS                   |
| Backend      | Node.js, Express.js                      |
| Real-time    | Socket.IO                                |
| Database     | MongoDB                                  |
| Auth         | JWT (JSON Web Tokens)                    |
| Deployment   | Render                                   |
